# Analysis-Online-Retail-with-PostgreSQL-Power-BI
Proyek Online Retail with PostgreSQL & Power BI ini bertujuan untuk mengoptimalkan strategi bisnis melalui analisis komprehensif terhadap 20.554 data transaksi, yang mencakup pembersihan data, analisis tren penjualan, serta prediksi pemulihan pendapatan pada bulan ke-14 (£1.046.903) dan ke-15 (£1.083.428). Menggunakan teknologi PostgreSQL dan Power BI, proyek ini mengimplementasikan metode Market Basket Analysis (MBA) dengan nilai lift 6,65 untuk strategi bundling produk, serta teknik segmentasi pelanggan berbasis RFM (Recency, Frequency, Monetary) guna memprioritaskan kategori pelanggan seperti Champion dan Loyal Big Spender dalam pengambilan keputusan stok dan promosi yang lebih presisi.
